# 🌍 Gloriane: Travel Recommendations

Gloriane is a travel recommendation web app that helps users discover their next destination. Search for beaches, temples, or countries and get inspired with suggestions picked for you.

**Live demo:** https://gloriane7767.github.io/travel-recommendation/

## About the Project

Planning a trip can be overwhelming, with endless options and too many tabs open at once. Gloriane simplifies that first step by letting travelers explore destinations through a simple search. Instead of sifting through long articles or crowded travel sites, users can type in a category such as beaches, temples, or countries and see recommendations they can browse right away.

The app is built as a lightweight, front-end-only website, so it loads quickly and needs no account or sign-up. The landing page, titled "Discover Your Next Adventure," puts the search bar front and center, and a Reset button lets users clear their results and start fresh. Supporting pages (About Us and Contact Us) give visitors background on the project and a way to reach out, while footer links connect to social media channels.

Gloriane is designed for casual travelers looking for inspiration, as well as anyone who wants a quick, distraction-free way to explore ideas before committing to a trip. It also works well as a foundation for future features such as filtering by region, saving favorites, adding traveler reviews, or showing local time and weather for each destination.

## Features

- Search for destinations by category (beaches, temples, countries)
- Reset button to clear results and start a new search
- Multi-page site with Home, About Us, and Contact Us pages
- Responsive layout with social media links in the footer
